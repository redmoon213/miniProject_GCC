# 보스 메쉬 분리 및 특수 패턴 구현 가이드

이 문서는 보스 캐릭터의 스태틱 메쉬를 위아래로 분리하고, 그 사이에서 공격이 나가는 특수 패턴(Split-Open Attack)을 구현하기 위한 기술적 가이드를 담고 있습니다.

---

## 1. 개요 (Overview)
- **목적:** 보스의 몸체가 위아래로 벌어지며 내부에 숨겨진 '코어'에서 탄막이나 레이저를 발사하는 시각적 연출 구현.
- **핵심 원칙:** 기존의 이동, 회전, 충돌 로직을 그대로 유지하면서 시각적 분리만 수행함 (부모-자식 구조 활용).

---

## 2. 단계 1: 메쉬 슬라이스 (Modeling Mode)
언리얼 엔진 5의 모델링 모드를 사용하여 메쉬를 물리적으로 두 조각으로 나눕니다.

1. **진입:** `Shift + 5` (Modeling Mode) 선택.
2. **도구:** `[MeshOps] -> [Slice]` 선택.
3. **설정:**
   - **절단면 배치:** 해골 마크 등 텍스처가 중요한 부분을 가로지르도록 주황색 평면 배치.
   - **UV 보존:** 기본적으로 UV가 유지되므로 텍스처 어긋남 없음.
   - **Output:** `Two Assets`로 설정하여 상단(`Upper`)과 하단(`Lower`) 메쉬를 각각 생성.
4. **결과:** 원래의 텍스처를 공유하는 두 개의 별도 스태틱 메쉬 에셋 확보.

---

## 3. 단계 2: 컴포넌트 구조 설정 (Hierarchy)
기존 로직과의 호환성을 위해 아래와 같은 계층 구조를 가집니다.

- **RootComponent (UBoxComponent):** 이동, 충돌, 월드 트랜스폼 담당.
  - **LowerBodyMesh (UStaticMeshComponent):** 바닥 측 자식. 위치 고정.
  - **UpperBodyMesh (UStaticMeshComponent):** 천장 측 자식. 애니메이션 시 Z축 이동.
  - **CorePosition (USceneComponent/UArrowComponent):** 벌어진 틈 사이의 발사 위치.

---

## 4. 단계 3: C++ 구현 전략

### 4.1 컴포넌트 관리
기존 `meshComp` 하나를 관리하던 방식에서 두 개를 동시에 제어하는 방식으로 확장합니다.
- **히트 플래시:** 두 메쉬의 `HitFlash` 파라미터를 동시에 업데이트.
- **가시성 제어:** 사망 시 두 메쉬를 모두 숨김 처리.

### 4.2 분리 애니메이션 (Timeline)
`UTimelineComponent`를 사용하여 위쪽 메쉬(`UpperBodyMesh`)의 `RelativeLocation`을 조절합니다.
- **Open:** Z값을 0에서 목표 높이(예: 150.0f)까지 보간.
- **Close:** Z값을 목표 높이에서 0으로 다시 보간.

### 4.3 공격 로직 연동
- 새로운 패턴 열거형 추가: `EBossPattern::CoreAttack`.
- 패턴 시작 시 `OpenBody` 애니메이션 실행 -> 완료 후 발사 로직 실행 -> 종료 전 `CloseBody` 실행.

---

## 5. 기대 효과 및 주의 사항
- **장점:** 텍스처가 완벽하게 이어지므로 분리 시 이질감이 없음. 기존 이동 코드를 100% 재사용 가능.
- **주의:** 잘린 단면(Cap)이 노출될 때 안쪽이 비어 보이지 않도록 별도의 '내부 메쉬'나 '에너지 효과'를 배치하는 것이 권장됨.
